# 🔤 فحوص أمان النصوص والحساب (tests/ui) — من v36.0، الخطوتان 1.10 و1.11

## ما هي؟
أسماء اللاعبين ونصوص الرسائل وبعض الأرقام يكتبها **مستخدمون آخرون** (أو تُقرأ من قاعدة البيانات). لو أُدرجت في
الصفحة كشيفرة HTML (`innerHTML`)، يستطيع من يضع في اسمه `<img src=x onerror=...>` أن يشغّل شيفرة على جهاز كل من
يرى اسمه. القاعدة في المشروع (`js/ui/safeText.js`):
- `textContent` حيث أمكن.
- في القوالب المُسندة إلى `innerHTML`: **كل** قيمة متغيّرة تمرّ بـ `esc()` عند موضع إدراجها — حتى نصوص الجداول الثابتة.
- HTML الثابت الوحيد المسموح بلا `esc`: أيقونات SVG من `getPowerIcon` (`js/ui/powerIcons.js` — SVG من جدولها أو احتياط مُهرَّب).
- روابط الصور: `safeImageSrc()` فقط — صور حسابات Google وحدها (https)، وتُعرض بلا referrer؛ غيرها = الحرف الأول.

ومنذ 1.11 (**حساب واحد لكل تحميل صفحة** — `js/session.js`): تسجيل الخروج (من الزر أو تبويب آخر أو انتهاء الجلسة)،
أو حساب آخر، أو ترقية الضيف = صفحة جديدة نظيفة؛ وبطاقة الصديق تتابع حضوره ما دامت ظاهرة فقط.

## ما تفحصه
**🛡️ الحارس الثابت** (`guard.mjs`) — يقرأ كل ملفات `js/` بمحلّل JavaScript حقيقي (acorn) ويمنع أي قيمة غير آمنة تصل إلى:
- **HTML**: قالب فيه وسوم، جمع نصوص (`+`) فيه وسوم، `innerHTML`/`outerHTML`/`srcdoc` بأي صيغة (`el.x`، `el["x"]`،
  كائن حرفي كـ`Object.assign`)، `insertAdjacentHTML`، `document.write`، `setHTMLUnsafe`، `createContextualFragment`، `parseFromString`.
- **رابط**: `.src`/`.href`/`.action`/`.srcset`/`.poster` و`setAttribute` لسمات الروابط، والتنقّل (`location = …`،
  `location.assign/replace`، `window.open`)، و`Reflect.set`/`Object.defineProperty` لهذه الخصائص (`esc` لا تكفي هنا — `safeImageSrc` فقط).
- **CSS**: `style.cssText` و`setAttribute("style")` (نص ثابت أو أرقام فقط).
- **شيفرة**: `setAttribute("on…")` بقيمة متغيّرة، `eval`، `new Function`، `setTimeout` بنص، و`document.write` كاسم مستعار.

يحلّ الأسماء بنطاقاتها الصحيحة: `esc` تُقبل فقط إن كانت **المستورَدة من safeText.js** (لا دالة محلية ولا معامل بالاسم
نفسه). ومعامل دالة يصل إلى HTML يُفحص **كل استدعاء لها** في الملف (والدالة لا تُصدَّر ولا تُمرَّر كقيمة). لا قائمة
"موثوق" بالنص إطلاقاً.
**🧪 الحارس نفسه** (`guardProbes.mjs`) — 60 نمطاً خطراً يجب أن يكشفها (منها ثغرات أثبتها المراجع على نسخه الثلاث الأولى)،
و15 نمطاً آمناً لا يعترض عليها. خارج قدرته (موثّق): خصائص CSS تقبل روابط مباشرة (`style.backgroundImage`)، و`setTimeout`
بمتغيّر نصّي، واسم خاصية محسوب من متغيّر، والأسماء المستعارة للكائنات العامة (`const w = window`) — لا يستعملها الكود.

**🔤 العرض الحقيقي** (`render.mjs` + `harness.mjs`) — يحمّل `index.html` الحقيقي في jsdom (محلّل HTML كالمتصفح)، ثم وحدات
الواجهة **الحقيقية** داخل النافذة نفسها، مع بدائل صريحة لما يكلّم Firebase. أسماء ورسائل خبيثة، والمطلوب: (أ) لا عنصر
محقون، (ب) النص يظهر حرفياً، (ج) الأسماء العادية والأرقام والأشكال كما كانت:
قائمة الرسائل · متصدرو تحدي اليوم · سجل المباريات (وأصناف بطاقاته من النتيجة) · بطاقات اللاعبين ونافذة معلومات اللاعب ·
شاشة النتيجة · نافذة الإحصائيات · أدوات `safeText.js` و`getPowerIcon`.

**🎮 اللعبة كاملة** (`app.mjs` + `fakeFirebase.mjs`) — `main.js` الحقيقي وكل وحداته الحقيقية فوق **Firebase وهمي في
الذاكرة** (بدائل وحدات gstatic الثلاث فقط: app/auth/database — بسلوك Firebase الحقيقي: `onAuthStateChanged` عند تغيّر
المعرّف فقط، والقراءة الأولى غير متزامنة، و`updateProfile` رحلة للخادم، و`onDisconnect().cancel()` لمساره فقط).
وضع **الاتصال البارد** (`cold`): كل العمليات تنتظر `fb.connect()` ثم تُطبَّق الكتابات المعلّقة قبل القراءات المعلّقة (كترتيب
الحزمة الحقيقية)، و`failNextGet` يرفض قراءة مسار مرة. وأي خطأ في مستمع غير متزامن (ضغطة زر…) يُلتقط ويُفشل الفحص. يفحص:
1. **حالة الأصدقاء حيّة** بعد إضافة صديق أو حذفه، ومستمع حضور واحد لكل صديق ظاهر، والمؤقّتات لا تتراكم (1.11-أ).
2. **الخروج**: الدعوة القائمة تُلغى (والغرفة) ثم صفحة جديدة (1.11-ب).
3. **خروج من تبويب آخر، دخول ثانٍ بنفس الصفحة، حساب آخر**: صفحة جديدة، ولا تهيئة فوق تهيئة (زر الرسائل يفتح بضغطة) (1.11-ب).
4. **ترقية الضيف** (Google وإيميل): الاسم والصورة تُحفظ في ملفه (بلا إيميل في الملف العام)، ثم صفحة جديدة تفتح كل الميزات (1.11-ج).
5. **التسجيل بإيميل**: الملف يُحفظ لحظة الدخول قبل وصول الاسم — ينتهي باسمه لا "لاعب" (والشريط كذلك)، وعلى **اتصال
   بارد** ملف كامل (uid/joinedAt/stats) لا "موجود ناقص" — وأول ما يصل الخادم تحت الملف هو الملف الكامل — و"لاعب" عالق
   أو ملف ناقص من قبل يُكمَل في الدخول التالي.
   (ونفسه بالحزمة الحقيقية وأزمنة شبكة حقيقية: `tests/realsdk` → `registrationProfile`.)
6. **حدث دخول مكرّر للحساب نفسه**: لا تهيئة ثانية ولا إعادة تحميل.
7. **أسماء الآخرين وصورهم** في الأصدقاء والبحث والطلبات والمتصدرين والمحادثة (مبنية بالـDOM — الحارس لا يراها): حرفية،
   وصور من مضيفين آخرين = الحرف الأول، وصورة Google بلا referrer، واسم ليس نصاً (رقم/مصفوفة/كائن) لا يكسر البحث
   ولا فتح المحادثة ولا حساب الإنجازات بعد المباراة، وفشل البحث يعيد الزر برسالة واضحة، وطلب الصداقة يذهب لصاحب الملف
   (مفتاحه) لا لحقل uid يكتبه هو. وطلبات الصداقة وقائمة الأصدقاء وإشعارات الرسائل بمفاتيح مدخلاتها لا بحقل uid يكتبه
   الطرف الآخر: "قبول" طلب يدّعي uid غيره لا يصادق شخصاً ثالثاً، وطلب بلا uid يُرفض، وإشعار رسالة الصديق يصل (ونصّها حرفي).

الأونلاين نفسه (قائمة المنضمّين، التصويت، لوبي الغرفة بالكود، "من N") يُفحص في المحاكي: `tests/sim` → قسم "🔤 أمان النصوص".

## التشغيل
```bash
cd tests/ui
npm install          # مرة واحدة (jsdom 26.1.0، acorn 8.14.1، acorn-walk 8.3.4 — نسخ مثبّتة)
npm test             # الحارس + الحارس نفسه + العرض الحقيقي + اللعبة كاملة (~20 ثانية)
node guard.mjs       # الحارس وحده
node --experimental-vm-modules --no-warnings run.mjs --only=اللعبة   # اللعبة كاملة وحدها
```
لفحص نسخة أخرى: `JAZAM_DIR=/path/to/project npm test`
(على v35.9: الحارس يجد 132 موضعاً غير آمن، وكل فحوص العرض الستة تفشل بعناصر محقونة، وفحوص اللعبة السبعة تفشل:
حالة الصديق تتجمّد ومؤقّتاتها تتراكم 1→12، الخروج بلا صفحة جديدة، الدخول الثاني يضاعف المستمعين 3→6 ويكسر زر الرسائل،
الترقية والتسجيل يُبقيان الاسم "لاعب"، صورة متتبّع تظهر، واسم ليس نصاً يكسر البحث للجميع والمحادثة والإنجازات.)
